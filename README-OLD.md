# الفلقي لتعديل PDF

نسخة جاهزة للنشر على GitHub Pages لتشغيل البرنامج من رابط HTTPS في المتصفح، بدل فتح ملف HTML محليًا.

## النشر على GitHub Pages

1. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository)، مثل `alfalqi-pdf`.
2. ارفع الملفات الموجودة في هذا المجلد إلى جذر المستودع، وبالأخص `index.html` و`.nojekyll`.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages، وسيكون عادةً بالشكل:
   `https://USERNAME.github.io/alfalqi-pdf/`
7. افتح الرابط في Safari أو Edge على iPhone، ثم جرّب اختيار ملف PDF وصورة من تطبيق «الملفات».

## ملاحظات مهمة

- لا أستطيع نشره داخل حساب GitHub الخاص بك أو إنشاء الرابط النهائي دون تسجيل دخولك ومنح صلاحية النشر.
- البرنامج يعتمد على بعض المكتبات التي تُحمّل من CDN؛ لذلك يلزم اتصال بالإنترنت عند فتح الموقع.
- ملفاتك تتم معالجتها محليًا داخل المتصفح في وظائف التحرير الأساسية، ولا يرفع هذا المشروع ملفات PDF إلى خادم خاص به.
- ميزة OCR تحتاج تحميل Tesseract وبيانات اللغة من الإنترنت.
- إذا لم يعمل اختيار الملفات داخل متصفح مضمّن في تطبيق ما، افتح رابط GitHub Pages مباشرة في Safari أو Edge.
- استخدم مستودعًا **Public** إذا أردت GitHub Pages المجاني المعتاد، ولا تضع مستنداتك الشخصية داخل المستودع.

## ما الذي تغيّر؟

- أصبح الملف الرئيسي باسم `index.html` كي يتعرف عليه GitHub Pages تلقائيًا.
- أضيفت آلية احتياطية لقراءة بيانات الملف عبر `FileReader` في المتصفحات التي لا توفر `Blob.arrayBuffer()`.
- بقيت وظائف التحرير الأصلية كما هي، ولم تُحذف أي أداة من الواجهة.


## تحديث OCR للصفحات المصوّرة
- أصبح بالإمكان تشغيل OCR على صفحات PDF العادية أيضًا، وليس الصور التي أُدخلت من أداة تحويل الصور فقط.
- تُحوّل الصفحة الممسوحة ضوئيًا مؤقتًا إلى صورة عالية الدقة قبل التعرف على النص.
- أضيفت إعدادات تقسيم صفحة OCR لتحسين التعامل مع الأسطر والفقرات.
- من شريط كل صفحة اختاري اللغة ثم «OCR / تحليل النص». كما يمكن تحليل جميع الصفحات من أدوات تحليل الصور.

ملاحظة: OCR العربي قد يخطئ في الجداول والخطوط الصغيرة أو المزخرفة. راجعي النص المستخرج قبل اعتماده، كما أن تعديل النص المستخرج يضيف طبقة نصية فوق الصورة ولا يعيد بناء النص الأصلي داخل الصورة تلقائيًا.
